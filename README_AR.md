
# نظام محاسبة مكتبي يعتمد على Excel

هذا مشروع مكتبي عربي بسيط لإدارة البيانات المحاسبية المستوردة من **اليومية الأمريكية** إلى قاعدة بيانات **SQLite**، مع واجهات تشغيل محلية على سطح المكتب.

## الوحدات الموجودة
- لوحة التحكم
- تسجيل الدخول والصلاحيات (مدير / محاسب / مشاهد)
- استيراد اليومية الأمريكية (مع مراكز التكلفة تلقائياً إن وجد عمودها)
- دفتر اليومية
- المدينون المتنوعون
- أذون الصرف الذكية
- الأستاذ العام
- ميزان المراجعة
- مراكز التكلفة
- التسويات البنكية
- المرتبات
- الملخص الشهري (فائض / عجز)

## الملفات
- `main.py` : تشغيل الواجهة
- `db.py` : قاعدة البيانات
- `importer.py` : استيراد ملف Excel
- `services.py` : التقارير والاستعلامات
- `pdf_reports.py` : طباعة التقارير والسندات PDF بالعربية
- `auth.py` : المستخدمون والصلاحيات
- `accounting.db` : قاعدة البيانات المستوردة مسبقاً من الملف المرفوع

## طريقة التشغيل
```bash
pip install -r requirements.txt
python main.py
```

## إنشاء ملف exe
```bash
pip install pyinstaller
python -m PyInstaller --noconfirm --clean SmartAccounting.spec
```
أو شغّل `build_exe.bat` (ملف واحد) أو `build_folder_app.bat` (مجلد تطبيق أكثر استقراراً).
يمكن أيضاً البناء من GitHub Actions: تبويب Actions ← Build Windows EXE ← Run workflow، أو بإنشاء tag باسم `v...` ليرفع الـ EXE تلقائياً في إصدار (Release).

## طباعة PDF
- كل الشاشات الرئيسية تحتوي زر «طباعة PDF» (اليومية، الميزان، الأستاذ العام، كشوف المدينين، الإيرادات والمصروفات، المرتبات، التقارير).
- من دفتر اليومية: اختر قيداً ثم «طباعة سند القيد» لإنشاء سند رسمي بالتوقيعات.
- من أذون الصرف الذكية: اختر أذن صرف ثم «طباعة أذن الصرف المحدد».
- مذكرات التسوية البنكية تطبع PDF مباشرة.
- الطباعة تستخدم خطاً عربياً من خطوط النظام (arial/Tahoma) تلقائياً.

## مراكز التكلفة
- تبويب «مراكز التكلفة»: إضافة / إعادة تسمية / حذف المراكز.
- عند إضافة أو تعديل قيد من دفتر اليومية، يمكن اختيار مركز التكلفة لكل سطر.
- **الاستيراد التلقائي**: إذا كان ملف اليومية يحتوي عموداً بعنوان «مركز التكلفة» (أو مركز تكلفة / مركز التكاليف / cost center) يُقرأ تلقائياً، وتُنشأ المراكز الجديدة وترتبط بها كل حركات القيد تلقائياً.
- تبويب «تقرير حركة المراكز»: تقرير بالحركات والرصيد التراكمي مع فلترة بالفترة والمركز، وتصدير Excel وطباعة PDF.

## المستخدمون والصلاحيات
- عند أول تشغيل سجّل الدخول بـ: `admin` / `admin` (غيّر كلمة المرور من إدارة المستخدمين).
- ثلاث صلاحيات:
  - **مدير النظام**: كل الصلاحيات + إدارة المستخدمين.
  - **محاسب**: استيراد، إضافة/تعديل/حذف القيود، التسويات، التصدير والطباعة.
  - **مشاهد**: مشاهدة الشاشات والتقارير فقط (كل أزرار التعديل والإدارة معطلة تلقائياً).
- شاشة «إدارة المستخدمين» في الإعدادات (للمدير فقط): إضافة / تعديل / تعطيل / حذف، وتغيير كلمات المرور.
- كلمات المرور محفوظة بشكل مشفر (hash) وليست نصاً صريحاً.

## الملخص الشهري (فائض / عجز)
- شاشة «الملخص الشهري» في التقارير: إيرادات ومصروفات وصافي كل شهر، مع فلترة بالسنة وتصدير Excel وطباعة PDF.
- زر «طباعة PDF» في شاشة ملخص الفائض/العجز يطبع الملخص النهائي المفصل.

## ملاحظات
- تم استيراد الملف `يومية امريكية 2022 12-3.xlsx` داخل قاعدة البيانات المرفقة.
- عند استيراد ملف جديد سيتم إعادة بناء الحسابات والقيود من جديد.
- أذون الصرف الذكية في هذه النسخة تستخرج الحركات التي يخرج فيها المبلغ من بنك/خزينة إلى حساب مستفيد.
- يمكن لاحقاً تطوير النظام إلى نسخة Electron أو إضافة صلاحيات متعدد المستخدمين ومراكز تكلفة تلقائية من ملف الاستيراد.
